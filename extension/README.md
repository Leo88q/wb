# Расширение Chrome для WB Ресейл

Заполняет форму объявления данными из локального дашборда. **Не публикует** и не обходит
защиту Wildberries: вы сами проверяете поля, прикрепляете фото и нажимаете «Опубликовать».

## Установка

1. Запустите локальный сервер: `python3 run.py` (по умолчанию `http://127.0.0.1:8000`).
2. Скопируйте `selectors.example.json` → `selectors.json` в этой папке.
3. Chrome → `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное» → выберите папку `extension/`.
4. Откройте сайт Wildberries, войдите в аккаунт, перейдите в **Ресейл → Мои объявления → Разместить объявление**.
5. В попапе расширения укажите адрес локального сервера, выберите карточку → **«Заполнить форму»**.

## Что делает

| Кнопка | Действие |
|---|---|
| Заполнить форму | Подставляет заголовок, описание, цену, размер, состояние в поля формы |
| Текст / Заголовок | Копирует в буфер (для ручной вставки, если вёрстка WB изменилась) |
| Фото | Скачивает обработанные кадры в `Загрузки/wb-resale/<артикул>/` — перетащите их в форму |
| ✓ Размещено | Меняет статус карточки в локальной БД и ставит дату следующего поднятия |

## Если поля не заполнились

WB регулярно меняет вёрстку. Откройте DevTools (F12) на странице формы, найдите нужный
`input`/`textarea`, скопируйте уникальный селектор и добавьте его первым в массив
в `selectors.json`. Расширение само покажет, какие поля не нашлись.

## Юридическая сторона

Это локальный инструмент автозаполнения (как менеджер паролей), а не бот. Он не
собирает данные аккаунта, не обходит капчу, не отправляет запросы вместо вас.
Массовая автоматическая публикация через UI-скрипты (см. `tools/autopublish.py`)
может нарушать правила площадки — используйте её на свой страх и риск и с разумными лимитами.
