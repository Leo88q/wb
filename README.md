# WB Ресейл Ассистент

Локальная система для продажи **300+ б/у платьев** через раздел «Ресейл» Wildberries:
автоматическая обработка фото, генерация описаний, размерный ряд и замеры,
планировщик «поднятия» карточек и AI-ассистент (веб + Telegram).

> Репозиторий `Leo88q/wb`, ветка `arena/317c19ca-wb`. Все данные лежат у вас на компьютере
> в `data/wb_resale.db`. Никаких облаков и ключей WB не требуется.

---

## Коротко: что можно и нельзя автоматизировать

| Хотелка | Реальность | Что делает эта система |
|---|---|---|
| Выгрузка фото | Публичного API для C2C-объявлений **нет** | Готовит фото пачкой (900×1200, 3:4, до 30 кадров, нумерация) и складывает в папки; расширение скачивает их в Загрузки, вы перетаскиваете в форму |
| Написание описаний | Можно полностью | Офлайн-шаблоны с ротацией + опционально LLM (в т.ч. vision по фото). Заголовок, текст, ключевые слова, честные дефекты |
| Размерный ряд | Можно полностью | RU ↔ INT/EU/US, таблица грудь/талия/бёдра, подбор размера по замерам, блок замеров в описании |
| Публикация карточек | Только через сайт/приложение | Расширение Chrome заполняет форму за секунды; есть полуавтоматический Playwright-сценарий (риск по правилам WB — по желанию) |
| Автоматическое «поднятие» | Кнопки/API «Поднять» **нет** | Планировщик редактирований: редактирование продлевает 2-месячный срок и освежает карточку, снижение цены пушует интересовавшимся. Очередь 10–15 в день с готовым текстом |
| Ассистент | Можно полностью | Веб-чат + Telegram-бот: помощь по процессу, переписывание описаний, расчёт цен, черновики ответов покупателям |

**Главный вывод:** автоматизируется ~85% рутины (контент, фото, размеры, цены, планирование),
но финальный клик «Опубликовать» остаётся за вами, потому что WB Ресейл — это C2C-сервис
внутри сайта/приложения без открытого API. Seller API (`/content/v2/cards/upload`) — это
**другой контур** для селлеров с ИП/самозанятостью и новых товаров, он не создаёт
ресейл-объявления. Заготовка клиента лежит в `app/wb_api.py` на случай, если WB его откроет.

## Фото больше 10 МБ — решается за один шаг

Официальный лимит WB: **до 10 МБ на файл**, JPG/PNG/WEBP, минимум **700×900 px**,
качество сжатия **не ниже 65%**, до **30 фото** на карточку и минимум 2 фото для поиска
[13](https://seller.wildberries.ru/instructions/ru/am/material/A-124?recommended=true)
[4](https://selsup.ru/blog/wildberries-skryvaet-tovary-v-gruzii-bez-foto-na-belom-fone-chto-delat-prodavtsam-do-23-iyulya/).
Оптимально 1–3 МБ — карточка быстрее грузится у покупателя
[3](https://fotofactor.ru/blog/marketplaces/wb-requirements).
Фото с телефона часто весят 10–20 МБ и просто не загружаются.

**Способ 1 — прямо в браузере (быстрее всего).** Откройте дашборд → вкладка
**«Контент и фото»** → блок **«⚡ Фото больше 10 МБ»** → выберите свою папку
(`/Users/zlata/Desktop/Одежда`) через кнопку выбора папки → **«Сжать и загрузить»**.
Браузер прочитает файлы локально, превратит каждый в вертикальный JPEG 3:4
1200×1600 (или 900×1200), уложит в 9.5 МБ (с запасом от лимита), сохранит
качество ≥65% и отправит на сервер уже маленькими. Исходники не изменяются.
Готовые кадры появятся в `data/out/DR-0001/01.jpg …`, а карточки — во вкладке
«Платья» со статусом `draft`. Отчёт «до/после» можно скачать кнопкой «Отчёт CSV».

**Способ 2 — скрипт на вашем Mac (надёжнее, умеет HEIC).** Ваша папка
`/Users/zlata/Desktop/Одежда` уже прописана по умолчанию:

```bash
cd /путь/к/репозиторию/wb
python3 -m pip install --user Pillow pillow-heif     # один раз, для HEIC с iPhone
python3 tools/prepare_photos.py                       # или двойной клик по prepare_photos.command
```

Результат: `/Users/zlata/Desktop/Одежда_WB/DR-0001/01.jpg …`, `report.csv`,
`inventory.csv`, `README.txt`. Скрипт сам группирует фото: **подпапка = одно платье**;
если все фото в одной куче — по умолчанию скрипт сортирует имена и группирует пары подряд: фото 1–2 = платье 1, фото 3–4 = платье 2.
Дополнительно: `--max-mb 3` (ещё легче), `--size 900x1200`, `--dry-run` (план без записи),
`--engine sips` (macOS без Pillow, встроенная утилита).

В тесте фото по 10.48 МБ превратились в 0.88 МБ (экономия 92%) при 1200×1600
и качестве 88 — запас до лимита огромный. Скрипт также убирает EXIF/GPS-метаданные
(важно, если снимали дома) и приводит цвет к sRGB.

**Дальше:** заполните `inventory.csv` (бренд, цвет, размер, замеры, цена) → импортируйте
его во вкладке «Контент и фото» → система добавит описания, размерный ряд и цены.
Артикулы `DR-0001…` должны совпадать с папками с фото. Два варианта без копирования:

* `--output "/путь/к/wb/data/incoming"` — затем импорт CSV с включённой галочкой
  «обработать фото из data/incoming» (фото пережмутся второй раз, но это безопасно);
* `--output "/путь/к/wb/data/out"` — готовые кадры сразу на месте; при импорте CSV
  **снимите** галочку «обработать фото из data/incoming», чтобы не пережимать повторно.

Если macOS не даёт открыть `.command` (Gatekeeper) — правый клик по файлу → «Открыть»,
либо выполните ту же команду `python3 tools/prepare_photos.py` в Терминале.

## Быстрый старт

```bash
cd wb
pip install -r requirements.txt          # только Pillow для фото (run.py поставит сам)
python3 run.py --port 8000 --seed-demo   # откройте http://localhost:8000
```

`--seed-demo` создаёт 300 демонстрационных платьев, чтобы потрогать интерфейс.
Для своих данных: вкладка **«Контент и фото»** → вставьте CSV → «Импортировать».
Шаблон на 300 строк: `data/inventory.example.csv`.

```bash
# Проверки

# Пример выгрузки конкурентов для ресерча цен
data/market.example.csv   # загрузите во вкладке «Исследование»
```

### Необязательно: AI-описания

```bash
export LLM_API_URL="https://api.openai.com/v1"   # любой OpenAI-совместимый endpoint
export LLM_API_KEY="..."
export LLM_MODEL="gpt-4o-mini"
export LLM_VISION=1                              # распознавать тип/цвет/состояние по фото
python3 run.py --port 8000
```

Без этих переменных всё работает офлайн: 5 вариантов формулировок, уникальные тексты,
никаких выдуманных фактов — только то, что вы указали в CSV.

## Как работать с партией из 300 платьев

1. **Нумерация.** Присвойте каждому платью артикул `DR-1001 … DR-1300` (бирка/стикер).
   Это ключ, по которому связываются фото, CSV, описание и очередь поднятий.
2. **Фото по шаблону** (5–8 кадров): общий план на вешалке, на человеке/манекене,
   бирка с размером, состав, замеры с рулеткой, дефекты крупным планом, фурнитура.
   Складывайте в `data/incoming/DR-1001/…`. Свет — дневной, фон — нейтральный.
3. **CSV.** Заполните `data/inventory.example.csv`: бренд, тип, цвет, материал, размер,
   состояние, дефекты, замеры (грудь/талия/бёдра/длина/рукав), цена, сезон, стиль.
   Русские названия колонок тоже принимаются (`Артикул;Бренд;Цвет;Размер;Цена`).
4. **Импорт.** Система за один проход: обработает фото, посчитает размерный ряд,
   сгенерирует заголовок/описание/ключи, предложит цену (с учётом медианы рынка).
   300 вещей обрабатываются параллельно в 6 потоков — минуты, а не часы.
5. **Публикация порциями по 20–30 в день.** Не выкладывайте 300 сразу: модерация
   и лимиты C2C-сервиса. Расширение Chrome (`extension/`) заполняет форму; фото
   перетаскиваются папкой из `data/out/<артикул>/`. После публикации нажмите
   «✓ Размещено» — карточка попадёт в график поднятий.
6. **Поднятие.** Раз в день откройте вкладку «Поднятие» → «Сгенерировать задачи».
   Выполняйте 10–15 задач: открыть объявление → Редактировать → вставить новый текст
   (кнопка копирования) → при желании снизить цену → Сохранить → «✓ Выполнено».
7. **Ответы покупателям.** В Ассистенте выберите вещь, режим «Ответ покупателю»
   и вставьте вопрос — получите вежливый черновик по фактам карточки.
8. **Ресерч раз в неделю.** Загрузите свежий CSV конкурентов → медиана/квартили →
   «Пересчитать мои цены по рынку».

## Ограничения Wildberries, которые важно знать

- Раздел «Ресейл» — C2C: продаёт физлицо с верифицированным **WB Кошельком**
  (подтверждение личности через Госуслуги), ИП/самозанятость не нужны.
- С февраля 2026 года можно выставлять вещи, купленные **где угодно**, а не только на WB
  (на практике функция раскатывалась постепенно — проверьте доступность в своём аккаунте).
- Объявление живёт **2 месяца**; редактирование продлевает срок. Размещение бесплатное,
  комиссия порядка **5–6%** с успешной сделки, оплата 100% предоплата, передача через ПВЗ.
- До 30 фото, габариты до 60×40×40 см, лимит цены уточняйте в приложении
  (в 2025 было 50–25 000 ₽, в 2026 писали про повышение до 100 000 ₽).
- Запрещены техника, ювелирка, лекарства, продукты, алкоголь, растения, 18+.
- С мая 2026 работает **торг** («Предложить цену»): снижение цены рассылает push
  всем, кто просил скидку, — это легальный способ «поднять» интерес к карточке.
- Не спамьте редактированиями и не используйте чужие аккаунты/обходы капчи:
  это основания для блокировки. Все скрипты здесь работают с вашим браузером и вашей сессией.

Источники и даты — в конце [docs/PLAN.md](docs/PLAN.md).

## FAQ

**Можно ли вообще выгрузить 300 объявлений по API одним запросом?**
Нет: такого метода у WB для Ресейла нет. Есть Content API для карточек селлеров
(`/content/v2/cards/upload`, до 100 карточек за запрос), но это товары селлера,
а не б/у объявления физлица. Наш экспорт JSON/CSV/ZIP — максимально близкая
замена: данные готовы, остаётся вставка в форму.

**А если всё-таки хочется «полностью автоматически»?**
`tools/autopublish.py` (Playwright) управляет вашим браузером, но это UI-автоматизация:
селекторы ломаются при обновлении сайта, а массовые действия могут нарушать правила WB.
Рекомендую гибрид: расширение + 20–30 публикаций в день.

**Что делать с «поднятием», если API нет?**
Редактирование объявления = обновление срока и «свежесть». Планировщик готовит
очередь, тексты и цены; финальное сохранение — вручную или через Playwright-режим
`--mode bump`. Так вы не зависите от недокументированных эндпоинтов.

**Где ассистент?**
Вкладка «Ассистент» в дашборде, плюс `tools/telegram_bot.py`. Он знает вашу базу,
умеет переписывать описания, считать цены, объяснять правила и готовить ответы
покупателям. Работает и без LLM (правила + шаблоны), с LLM — естественнее.
