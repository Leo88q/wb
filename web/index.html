Вся воронка: от фото до поднятия объявлений

Важно про автоматизацию. У WB Ресейл нет публичного API для частных объявлений: Seller API — это другой контур (карточки селлеров, новые товары). Поэтому автоматизируем подготовку (фото → описание → размеры → цена → экспорт), а публикацию ускоряем расширением браузера и планировщиком редактирований.

    Настройки поднятий

    Редактирование объявления в Ресейле продлевает срок публикации (2 месяца) с момента правки. Снижение цены пушует тех, кто просил скидку. Не делайте больше 15–20 правок в день — это выглядит как спам.

    Как устроен конвейер

    AI-описания

    Без ключа работает офлайн-генератор: 5 вариантов формулировок, честное состояние, замеры, ключевые слова. Чтобы включить LLM, задайте переменные окружения перед запуском:
    LLM_API_URL (OpenAI-совместимый endpoint), LLM_API_KEY, LLM_MODEL, LLM_VISION=1 — для распознавания по фото.

    Нажмите «Пример описания» — покажу, какой текст получится.
    Автоматической кнопки «Поднять» в Ресейле нет. Редактирование объявления обновляет срок публикации, а снижение цены рассылает push интересовавшимся. Здесь — очередь таких обновлений вручную или через Playwright-сценарий.
